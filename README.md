## Publish with GitHub + Vercel (free)
1. Create a GitHub account if you do not already have one.
2. Create a new repository, e.g. `priyanka-portfolio`.
3. Upload **all files and the entire `assets` folder** from this project.
4. On Vercel, choose **Add New Project** → import the GitHub repository.
5. Framework preset: **Other** (or leave it as detected).
6. Build command: leave blank.
7. Output directory: leave blank.
8. Click **Deploy**.
9. Vercel will give you a permanent public URL such as `your-project.vercel.app`.
10. Later you can connect a custom domain.

## Important before making it public
The two community fieldwork photos contain GPS/location overlays and a vehicle registration plate. Consider replacing them with cropped/clean versions before public deployment if you do not want those details online.
