# Priyanka — Portfolio Site

A simple static website version of the portfolio PDF, ready to publish for free with GitHub Pages.

## Files in this folder

- `index.html` — the site
- `style.css` — styling
- `profile.jpg` — your photo
- `Priyanka-Portfolio.pdf` — the original PDF (linked from the "Download full PDF" button)

## Publish it with GitHub Pages (no coding needed)

1. Go to [github.com](https://github.com) and create a **new repository** (e.g. `portfolio`). Make it **Public**.
2. On the repo page, click **Add file → Upload files**.
3. Drag in all four files above (`index.html`, `style.css`, `profile.jpg`, `Priyanka-Portfolio.pdf`) and click **Commit changes**.
4. Go to **Settings → Pages** (left sidebar).
5. Under **Build and deployment → Source**, choose **Deploy from a branch**.
6. Under **Branch**, select `main` and folder `/ (root)`, then click **Save**.
7. Wait about a minute, then refresh — GitHub will show your live link, something like:
   `https://your-username.github.io/portfolio/`

That link is what you can share with anyone — it opens the page directly, and the "Download full PDF" button lets visitors save the original PDF too.

## Making changes later

Edit `index.html` (content/text) or `style.css` (colors/layout) directly on GitHub — click the pencil icon on the file, edit, and commit. The live site updates automatically within a minute of each commit.
